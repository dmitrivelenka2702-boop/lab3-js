# Лабораторна робота №3 з JavaScript

## Завдання
Реалізувати видалення та зміну даних у таблиці.

## Реалізація

Усі дані зберігаються у масиві `students` у файлі `script.js`.

HTML містить лише структуру сторінки, форму та порожній `tbody`.
Рядки таблиці створюються динамічно засобами JavaScript.

Реалізовано:
- додавання нового запису;
- видалення запису з підтвердженням;
- редагування запису через форму;
- зміну імені натисканням на клітинку;
- повторний рендер таблиці після кожної зміни.

Після додавання, редагування або видалення змінюється масив `students`,
а функція `renderStudents()` заново формує таблицю.

Сторонні бібліотеки, фреймворки та готові рішення не використовуються.
